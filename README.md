This is just the Zend_Auth component extracted from our fork of the Zend Framework 1 repo (https://github.com/gizmocraftcom/zf1). Optional adapters may have to be installed separately.

The optional OpenId adapter (`zendframework1-auth-adapter-openid`) is not part of the gizmocraft forks, because it depends on the excluded `Zend_OpenId` package. The `suggest` entry for it was dropped.

Originally forked from the upstream repository https://github.com/diablomedia/zf1-auth. Copyright and license of the original authors are kept in LICENSE.txt.
